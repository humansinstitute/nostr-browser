# WMAPP 0.1.5

Android embedded FIPS diagnostics update.

- Adds an app-owned, durable FIPS lifecycle journal that survives WMAPP process restarts and retains the newest 200 records up to 128 KiB.
- Adds **Export diagnostics** and **Clear diagnostics** controls under **Setup → FIPS transport**, available even when FIPS failed to start.
- Uses Android's user-controlled document picker, needs no storage permission, and reports successful, cancelled, and failed exports without blocking retry or repair.
- Records only allowlisted lifecycle metadata needed to distinguish native preparation, VPN consent, foreground service promotion, VPN establishment, native readiness, timeout/cancellation, activity destruction, and Flutter retry/export boundaries.
- Deliberately excludes private keys, nsec, Nostr events, NIP-98/Authorization tokens, bunker/NWC/capability material, certificate or identity secrets, sensitive paths, request/response payloads, browsing history, arbitrary WebView URLs, stack traces, and system logcat.

This release adds evidence collection; it does not claim to fix the Daylight tablet-specific startup failure. After reproducing the failure, export the file from Setup and attach it to the diagnostic report.
