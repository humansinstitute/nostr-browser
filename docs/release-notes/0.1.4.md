# WMAPP 0.1.4

Android embedded FIPS first-run reliability update.

- Makes VPN consent, cancellation, startup, timeout, and retry complete safely without stranding WMAPP.
- Moves Android VPN preparation and consent launching onto the activity thread and adopts the Activity Result API.
- Converts native preparation, foreground-service, notification, and VPN establishment failures into concise recoverable status.
- Adds privacy-safe FIPS lifecycle event codes for future device logcat diagnosis.
- Preserves split mesh routing, Android-managed public DNS, `.fips` DNS, protected transport sockets, and persistent FIPS identity.

Android's notification runtime permission is not required to start this foreground VPN service. If notifications are denied on Android 13 or later, Android still exposes the active foreground service in Task Manager; WMAPP requests only the system VPN consent needed for the embedded tunnel.
