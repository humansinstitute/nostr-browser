# WMAPP 0.1.3

Android FIPS connectivity and reliability update.

- Adds an embedded Android VPN interface for routing `.fips` WApp traffic to the bundled FIPS node.
- Hardens FIPS startup, repair, shutdown, and VPN lifecycle handling.
- Preserves public DNS through Android's selected non-VPN network while resolving `.fips` names locally.
- Enables access to FIPS WApps from WMAPP's embedded browser without changing their trusted origin.
