# WMAPP 0.1.7

Adds an optional local diagnostics capability for Flight Deck reports.

- Native consent permits sanitized browser evidence and limited host event
  categories in the current origin, document, unlocked identity, tab and
  workspace. Navigation, reload, background/OS lock and identity replacement revoke access.
- Saved evidence can recover after reload or restart only for the restored tab
  and matching origin, identity and workspace, after fresh native consent.
- Both individual buffers and the entire local native store are bounded to
  30 minutes and 512 KiB; abandoned contexts are pruned. Grants are never saved.
- Evidence excludes page text, bodies, headers, messages, screenshots, endpoint
  identities and arbitrary application logs. Flight Deck sends reports through
  its existing signed chat/file flow; this capability adds no network bridge.

Host evidence covers document readiness, app lifecycle transitions, main-frame
WebView resource errors and available generic transport lifecycle categories.
A 30-second native-only same-origin transition preserves load failure evidence
after browser access is revoked. WebKit content-process termination records a
bounded error and revokes the document; Android renderer termination is not
separately exposed by the current controller. It does not provide OS crash
dumps or crash-time sending. Native capability is available only where the
existing channel verifies top-level frame origin: Android, iOS and macOS.

## Validation procedure

Run Flutter analyze/tests. Build supported local artifacts, refresh the embedded
Flight Deck bundle from a verified source build, and inspect the included
version. On an explicitly authorized test device, opt in, record an error,
reload, verify fresh consent and recovery, then verify navigation, workspace
switch, lock and tab closure deny access. A native build alone does not establish
physical device acceptance or live installation.

The reusable protocol and fixtures are in
[diagnostics-protocol.md](../diagnostics-protocol.md) and
[diagnostics-fixtures.json](../diagnostics-fixtures.json).
